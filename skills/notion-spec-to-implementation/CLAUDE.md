# notion-spec-to-implementation/

Turns product/tech specs into concrete Notion tasks for Claude Code implementation.

## Files

| File       | What                          | When to read                             |
| ---------- | ----------------------------- | ---------------------------------------- |
| `SKILL.md` | Invocation syntax and prompts | Using this skill, understanding workflow |

## Subdirectories

| Directory      | What                              | When to read                          |
| -------------- | --------------------------------- | ------------------------------------- |
| `examples/`    | Sample spec breakdowns            | Understanding expected task formats   |
| `reference/`   | Templates and parsing guides      | Customizing task output, spec parsing |
| `evaluations/` | Test cases for skill quality      | Running or modifying evaluations      |
