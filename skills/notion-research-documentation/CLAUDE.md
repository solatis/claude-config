# notion-research-documentation/

Searches Notion workspace, synthesizes findings, and creates research documentation.

## Files

| File       | What                          | When to read                             |
| ---------- | ----------------------------- | ---------------------------------------- |
| `SKILL.md` | Invocation syntax and prompts | Using this skill, understanding workflow |

## Subdirectories

| Directory      | What                              | When to read                          |
| -------------- | --------------------------------- | ------------------------------------- |
| `examples/`    | Sample research outputs           | Understanding expected output formats |
| `reference/`   | Format templates and search guides| Customizing output, advanced search   |
| `evaluations/` | Test cases for skill quality      | Running or modifying evaluations      |
