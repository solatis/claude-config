# notion-knowledge-capture/

Transforms conversations into structured Notion documentation pages.

## Files

| File       | What                          | When to read                             |
| ---------- | ----------------------------- | ---------------------------------------- |
| `SKILL.md` | Invocation syntax and prompts | Using this skill, understanding workflow |

## Subdirectories

| Directory      | What                         | When to read                          |
| -------------- | ---------------------------- | ------------------------------------- |
| `examples/`    | Sample conversation captures | Understanding expected output formats |
| `reference/`   | Database-specific templates  | Targeting specific Notion databases   |
| `evaluations/` | Test cases for skill quality | Running or modifying evaluations      |
